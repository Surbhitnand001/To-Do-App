===============================================
STEP 6: LOCAL STORAGE PERSISTENCE
===============================================

OBJECTIVE:
Save tasks to browser's localStorage so they persist after page refresh

KEY CONCEPTS LEARNED:
- useEffect hook for side effects
- localStorage API (browser storage)
- JSON.stringify() and JSON.parse()
- Dependency arrays in useEffect
- useRef for tracking renders
- Date object handling in localStorage

CODE EXAMPLE:
--------------
import { useEffect, useState, useRef } from "react";

function App() {
  const [allTasks, setAllTasks] = useState([]);
  const isFirstRender = useRef(true);

  // LOAD tasks when app starts
  useEffect(() => {
    const saved = localStorage.getItem("tasks");
    if (saved) {
      const parsed = JSON.parse(saved);
      const tasksWithDates = parsed.map((task: any) => ({
        ...task,
        time: new Date(task.time),  // Convert string back to Date
      }));
      setAllTasks(tasksWithDates);
    }
  }, []); // Empty array = run once on mount

  // SAVE tasks whenever they change
  useEffect(() => {
    if (isFirstRender.current) {
      isFirstRender.current = false;
      return;  // Skip saving on first render
    }
    localStorage.setItem("tasks", JSON.stringify(allTasks));
  }, [allTasks]); // Run whenever allTasks changes
}

UNDERSTANDING useEffect:
------------------------
useEffect(() => {
  // Code to run
}, [dependencies]);

- Runs code at specific times (not during render)
- First parameter: Function to execute
- Second parameter: Dependency array (when to run)

DEPENDENCY ARRAY OPTIONS:
--------------------------
useEffect(() => {...}, [])           → Run ONCE on mount
useEffect(() => {...}, [count])      → Run when 'count' changes
useEffect(() => {...}, [a, b])       → Run when 'a' OR 'b' changes
useEffect(() => {...})               → Run on EVERY render (avoid!)

LOCALSTORAGE API:
-----------------
localStorage.setItem(key, value)     → Save data
localStorage.getItem(key)            → Retrieve data
localStorage.removeItem(key)         → Delete data
localStorage.clear()                 → Delete everything

Important: localStorage only stores STRINGS!

JSON CONVERSION:
----------------
JSON.stringify() → Convert object/array to string
JSON.parse()     → Convert string back to object/array

Example:
const tasks = [{text: "Buy milk", completed: false}];

JSON.stringify(tasks)
→ '[{"text":"Buy milk","completed":false}]'  (STRING)

JSON.parse('[{"text":"Buy milk","completed":false}]')
→ [{text: "Buy milk", completed: false}]  (ARRAY)

THE DATE PROBLEM:
-----------------
When you save: { time: Date object }
After JSON.stringify: { time: "2026-01-22T10:30:00.000Z" }  (STRING!)
After JSON.parse: { time: "2026-01-22T10:30:00.000Z" }  (STILL STRING!)

Calling .toLocaleTimeString() on a string → ERROR!

Solution:
parsed.map(task => ({
  ...task,
  time: new Date(task.time)  // Convert string back to Date object
}))

UNDERSTANDING useRef:
---------------------
const isFirstRender = useRef(true);

- Creates a mutable value that persists across renders
- Changing .current does NOT trigger re-render
- Perfect for tracking "has this run before?"

isFirstRender.current = true   → It's the first render
isFirstRender.current = false  → Not the first render anymore

WHY SKIP FIRST RENDER?
----------------------
Problem without skip:
1. Page loads → allTasks = []
2. Save effect runs → Saves [] to localStorage (DELETES YOUR TASKS!)
3. Load effect runs → Tries to load, but localStorage is empty now

Solution with skip:
1. Page loads → allTasks = []
2. Save effect checks isFirstRender → TRUE → Skips saving
3. Load effect runs → Loads tasks from localStorage
4. Next time allTasks changes → Save effect runs normally

THE TWO EFFECTS:
----------------
LOAD Effect:
- Runs: ONCE when app starts
- Purpose: Retrieve saved tasks
- Dependency: [] (empty - run once)

SAVE Effect:
- Runs: Every time allTasks changes
- Purpose: Keep localStorage in sync
- Dependency: [allTasks]
- Special: Skips first render with useRef

FLOW DIAGRAM:
-------------
User adds task
    ↓
allTasks changes
    ↓
Save effect runs
    ↓
localStorage updated
    ↓
User refreshes page
    ↓
Load effect runs
    ↓
localStorage read
    ↓
allTasks updated
    ↓
Tasks appear on screen!

ALTERNATIVE APPROACH (More common):
------------------------------------
Initialize state from localStorage directly:

const [allTasks, setAllTasks] = useState(() => {
  const saved = localStorage.getItem("tasks");
  if (saved) {
    const parsed = JSON.parse(saved);
    return parsed.map(task => ({
      ...task,
      time: new Date(task.time)
    }));
  }
  return [];
});

// Only one useEffect needed to save
useEffect(() => {
  localStorage.setItem("tasks", JSON.stringify(allTasks));
}, [allTasks]);

Benefits:
- No useRef needed
- No race conditions
- Loads before first render
- Simpler code

This is the industry standard approach used by GitHub, VS Code, etc.
