1. DARK/LIGHT THEME TOGGLE
===========================

WHAT IT DOES:
- Switches between dark and light color schemes
- Toggle button in top-right corner
- Sun icon (☀️) in dark mode, moon icon (🌙) in light mode

CODE:
-----
const [isDarkMode, setIsDarkMode] = useState(true);

<div className={`app ${isDarkMode ? "dark" : "light"}`}>
  <button onClick={() => setIsDarkMode(!isDarkMode)}>
    {isDarkMode ? "☀️" : "🌙"}
  </button>
</div>

CSS uses conditional classes:
.app.dark { background: #000; color: #fff; }
.app.light { background: #f5f5f5; color: #000; }

KEY CONCEPTS:
- Template literals with embedded expressions
- Ternary operator for conditional rendering
- CSS class-based theming


2. GRID CARD LAYOUT
====================

WHAT IT DOES:
- Displays tasks as cards in a responsive grid
- Automatically adjusts columns based on screen size
- Cards lift on hover with blue border

CSS:
----
.tasks-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 20px;
}

KEY CONCEPTS:
- CSS Grid layout
- Responsive design with auto-fill
- minmax() for flexible sizing
- Hover effects and transitions

4. DELETE BUTTON (×) WITH HOVER
================================

WHAT IT DOES:
- Shows red × button when hovering over task card
- Scales up on hover for visual feedback

CSS:
----
.btn-close {
  opacity: 0;  /* Hidden by default */
}

.task-card:hover .btn-close {
  opacity: 1;  /* Show on card hover */
}

.btn-close:hover {
  color: #ff0000;
  transform: scale(1.2);
}

KEY CONCEPTS:
- CSS opacity for show/hide
- Nested hover selectors
- Transform for scaling
